# JS Básico — Proyectos de práctica

Repositorio con proyectos pequeños hechos para practicar JavaScript (vanilla, sin frameworks) después de completar un curso de fundamentos del lenguaje: estructuras de datos, bucles, funciones, objetos, destructuring/spreading, clases, manejo de errores, métodos de consola y módulos.

Cada proyecto está en su propia carpeta, con su propio `README.md` detallando funcionalidades, tecnologías usadas y aprendizajes clave.

## Proyectos

| Proyecto | Descripción | Carpeta |
|---|---|---|
| 🧮 Calculadora | Calculadora funcional con teclado numérico en pantalla y soporte de entrada por teclado físico. | [`/Calculadora`](./Calculadora) |
| ✅ To-Do List | Lista de tareas con creación, edición, búsqueda, completado y persistencia en `localStorage`. | [`/To-do-list`](./To-do-list) |

## Stack común

- HTML5 semántico
- CSS3 (Grid, Flexbox, variables CSS)
- JavaScript ES6+ (clases, manejo de eventos, `try/catch`, delegación de eventos)

Sin frameworks, sin build tools — cada proyecto corre abriendo directamente su `index.html`.

## Sobre este repositorio

Estos proyectos forman parte de mi proceso de aprendizaje de JavaScript, construidos paso a paso resolviendo bugs reales, iterando sobre la arquitectura del código y revisando buenas prácticas (delegación de eventos, separación de responsabilidades, validación de datos, manejo de errores personalizado).

## Cómo usar este repositorio

```bash
git clone <url-de-este-repositorio>
cd <nombre-del-repo>
```

Luego entrar a la carpeta del proyecto que te interese y abrir su `index.html` en el navegador.
