# JavaScript Básico — Proyectos

Repositorio de proyectos realizados durante mi aprendizaje de **JavaScript**, después de completar un curso de fundamentos del lenguaje.

La idea de estos proyectos fue llevar los conceptos estudiados a aplicaciones funcionales y resolver por mi cuenta los problemas que fueron apareciendo durante el desarrollo.

## 🚀 Proyectos

| Proyecto | Descripción | Demo |
|---|---|---|
| 🧮 **Calculadora** | Calculadora funcional con entrada mediante botones y teclado físico. | [Ver demo](./Calculadora/) |
| ✅ **To-Do List** | Aplicación para crear, editar, buscar, completar y eliminar tareas, con persistencia mediante `localStorage`. | [Ver demo](./To-do-list/) |

## 🛠️ Tecnologías

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM
- Eventos
- Clases
- Manejo de errores
- `localStorage`

No se utilizan frameworks, librerías externas ni herramientas de build.

## 📚 Qué practiqué

- Manipulación del DOM.
- Gestión de eventos.
- Clases y objetos.
- Arrays y métodos como `filter()`, `find()` y `sort()`.
- Delegación de eventos.
- Validación de datos.
- Manejo de errores con `try/catch`.
- Persistencia de información con `localStorage`.
- Serialización mediante `JSON.stringify()` y `JSON.parse()`.
- Organización de la lógica de una aplicación.
